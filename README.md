## 🚀 How to Run Locally

### Option 1: Double-click
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Using Node / npx
```bash
npx serve .
# or
npx http-server .
```

### Option 3: Using Python
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🌐 Deployment Options

- **Vercel / Netlify**: Drag-and-drop the folder or link your Git repository. Zero build step required.
- **GitHub Pages**: Push this repository to GitHub and enable Pages in Repository Settings -> Pages.
- **Cloudflare Pages / cPanel**: Upload `index.html` and `assets/` directory.
